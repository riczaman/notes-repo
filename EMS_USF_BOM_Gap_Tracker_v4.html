EMS integration: BOM feedback and show-stopper decisions

The BOM feedback log consolidates into 22 issues. None has been confirmed as a show-stopper. Expand any issue for the problem, what BOM users said, requirements and proposed tests.

Current position: leadership and the EMS business team decide whether any item is a show-stopper. If it is, we fix it before deployment. If it is not, we deploy and work it as a fast follow.

Proposed show-stopper test (for leadership and EMS to confirm)

  • Could a request reach the wrong route or approval path?
  • Could an approval be invalid for audit?
  • Could BOMs be unable to run a Signing Party?
  • Is there no acceptable interim workaround?
